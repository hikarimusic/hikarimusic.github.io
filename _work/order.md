## Cardiovascular

### Chest pain

* Troponin-T (repeat Q3H)
* EKG
* Chest X-ray
* Chest CT (CTA)
* Nitroglycerin 0.6mg PRN SL

### Heart Failure

* NT-proBNP
* EKG
* Chest X-ray
* Furosemide 20mg Q6H IV
* Bumetanide 1mg Q6H IV
* O2 cannula/mask

### Arrhythmia

* Na, K, Ca, Mg
* TSH
* EKG
* Propranolol 10mg TID PO
* Diltiazem 12.5mg STAT IF (NS 100mL, run 100min)
* Amiodarone 150mg QD IF (D5W 100mL, run 30min)
* Amiodarone 900mg QD cIF (D5W 500mL, run 1440min)
* Adenosine 6mg STAT IV
* Adenosine 12mg STAT IV
* Atropine 1mg STAT IV
* Cardioversion

### Hypertension

* Cre
* EKG
* Amlodipine 5mg QD PO
* Captopril 25mg TID PO
* Labetalol 20mg PRN IV (repeat Q10min)
* Nicardipine 20mg QD IF (NS 100mL, run 5ml/hr)

### Shock

* CBC, DC
* PT, aPTT
* Lactate
* ABG/VBG
* Blood culture x2
* EKG
* Chest X-ray
* Ultrasound (FAST)
* NS 1000mL STAT IF (run 60min)
* Norepinephrine 8mg QD cIF (D5W 250 mL, run 5 mL/hr)
* Vasopressin 60U QD cIF (NS 100 mL, run 4 mL/hr)
* Piperacillin 4000mg Q6H IF (NS 100 mL, run 30min)
* Transfuse RBC 2U

### Acute coronary syndrome

* Troponin-T (repeat Q3H)
* PT, aPTT
* T-CHO, HDL, LDL, TG
* EKG
* Nitroglycerin 0.6mg STAT SL
* Aspirin 300mg STAT PO
* Clopidogrel 300mg STAT PO
* Heparin 4000U STAT IV
* Heparin 25000U QD cIF (NS 250 mL, run 12U/kg/hr)
* Morphine 4mg PRN IV
* O2 cannula/mask
* Consult CV

### Cough

* ABG/VBG

* High flow O2 cannula
* BiPAP
* Mechanical ventilator

## Renal

### Hyperkalemia

* 12-lead EKG
* Calcium gluconate 9.3 mEq STAT IF (in NS 100 mL, run 120 min)
* Insulin regular 8 U STAT IV
* Dextrose 50% 40 mL STAT IV
* Sodium bicarbonate 49.8 mEq STAT IV
* Kalimate 3 pack TID PO
* Furosemide 20 mg STAT IV

### Hypokalemia

* 12-lead EKG
* Potassium gluconate 40 mEq STAT PO
* Potassium chloride 20 mEq STAT IF (in NS 500 mL, run 120 min)
* Magnesium sulfate 16 mEq STAT IF (in NS 100 mL, run 60 min)

### Hypernatremia

* D5W 1000 mL STAT IF (run 240 min)
* Furosemide 20 mg STAT IV

### Hyponatremia

* Sodium chloride 0.9% 1000 mL STAT IF (run 240 min)
* Sodium chloride 3% 100 mL STAT IF (run 10 min)

### Hypercalcemia

* Normal saline 1000 mL STAT IF (run 120 min)
* Furosemide 20 mg STAT IV

* Cr, BUN

## Hematologic

### Anemia

* PT / aPTT
* Stool OB
* RBC 2U transfusion (if Hb < 7)
* Diphenhydramine 30 mg STAT IF (in NS 100 mL, run 15 min, before transfusion)
* Fe(III) 100mg QD PO

###  Thrombocytopenia

* PT / aPTT
* Fibrinogen / D-dimer
* Platelet 12U transfusion (if Plt < 10,000)

### Coagulopathy

* PT / aPTT
* Fibrinogen / D-dimer
* FFP 2U transfusion (if active bleeding)
